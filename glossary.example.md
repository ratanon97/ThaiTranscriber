# Glossary for transcript correction

Copy this file to `glossary.md` (gitignored) and keep it up to date. It is
sent to the correction LLM with every chunk, so keep it short and specific:
names, nicknames, places, and recurring terms the ASR tends to mishear.

Format is free text; one entry per line works best.

## People
- สมชาย (Somchai) — the person recording; often addressed as "คุณสมชาย"
- สมหญิง (Somying) — Somchai's colleague
- น้อย (Khun Noi) — project coordinator; ASR often writes "น้อย" with the wrong tone marker

## Places
- ถนนสุขุมวิท (Sukhumvit Road) — office location

## Terms
- ประชุม (prachum) — meeting
- งบประมาณ (ngop praman) — budget
- Interest, asset, income, growth, world equity index — finance terms spoken in English; write them in English
